# JR / R—Net Design System — Short Spec

*One paragraph for AI system prompts. Use when context is tight.*

Design in the JR / R—Net "Charts & Vectors" system: a single visual language for both personal/ceremonial work (correspondence, monograms, formal docs on warm paper) and instrumented/technical work (R—Net dashboards, system status, infrastructure docs on warm charcoal). Typography uses **Outfit** (display/headings, weight 500–600), **Urbanist** (body, weight 400/600, line-height 1.65+), and **JetBrainsMono Nerd Font** (labels, metadata, glyphs, inline technical terms — always with 2.5px tracking when uppercase). No italics on names or headlines. Palette is organized in four layers that never mix roles: **surfaces** (light: `paper-true` #FAF6EC, `paper-chart` #FCF4DF, `urban` #F8E4AE callout-only; dark: `night` #1C1E1C, with elevations `night-2` #252824, `night-3` #2F322D); **structure** (`ink` #1F1D18 primary, `graphite` #6B675C secondary, `panel-light` #D4CEBC borders; dark: `cream` #EDE8D8 primary); **brand** sourced from aircraft cockpit instrumentation (`sky` #6B9BB8 + `sky-deep` #4A7A96 for personal/light accent, `ground` #8B5A3C + `ground-deep` #6B4226 for warm secondary, `amber` #D49826 + `amber-glow` #F0B84A for R—Net/dark accent — **amber is dark-mode only, fails WCAG on light surfaces**); and **semantic** R/Y/G for status only (`ok-fg` #4A7A3A / `ok-bg` #D8E0C8, `warn-fg` #7A5A10 / `warn-bg` #F5E4A8, `alert-fg` #A8362A / `alert-bg` #ECC8C0). Use one brand accent per context (sky in light, amber in dark) in at most three places per page. Never mix brand colors with semantic colors — they live in separate conceptual layers. Industrial grammar primitives: 4px accent stripe at top of pages/panels; corner brackets on cards; numbered section headers ("01 ▸ TITLE ──── META"); data calipers for counts; dotted rules for TOC leaders only; registration marks rarely. Use 2–3 industrial elements per document maximum. Glyphs come from JetBrainsMono Nerd Font (83 sanctioned roles like `status-ok` U+F00C, `infra-server` U+F233, `loc-aviation` U+F072 — prefer Font Awesome codepoints which are stable). Generous negative space; minimum 48px page padding, 72px between sections, 1.65 line-height. The system is not corporate, not maximalist, not skeuomorphic, not startup-deck — it must serve both a thank-you note and a 50-page infrastructure report without either feeling forced. When in doubt: remove rather than add, restraint rather than elaboration.
