# Font Hosting — cdn.rossie.net

Self-hosted webfonts for the JR / R—Net design system. All three faces — JetBrainsMono
Nerd Font, Outfit, and Urbanist — are served from `cdn.rossie.net`. No third-party font
CDN (`cdn.jsdelivr.net`, `fonts.googleapis.com`) is used at runtime.

## What's in this folder

| File | Purpose |
|------|---------|
| `JetBrainsMonoNerdFont-Regular.ttf` / `-Medium.ttf` | Source fonts, Nerd Fonts v3.4.0. Kept for re-subsetting; **not** deployed. |
| `build-fonts.sh` | Rebuilds every production webfont below. Run after changing the source `.ttf` or the GLYPHS.md catalog. |
| `UNICODE-RANGE.css` | Generated by `build-fonts.sh`. The `unicode-range` to paste into the `-min` `@font-face` rules in `style-guide.html`. |
| `cloudflare-deploy/` | **The exact folder to upload to Cloudflare Pages.** Contains `index.html`, `_headers`, and `fonts/*.woff2`. |
| `HOSTING.md` | This file. |

### Production webfonts (`cloudflare-deploy/fonts/`)

| File | Size | Notes |
|------|------|-------|
| `jetbrains-mono-nerd-{regular,medium}-min.woff2` | ~23 KB each | **Minimum subset** — ASCII + Latin-1 + common punctuation + the 87 glyphs sanctioned in `GLYPHS.md`. This is what `style-guide.html` loads. |
| `outfit-latin-var.woff2` / `urbanist-latin-var.woff2` | ~32 / ~28 KB | Variable weight (200–800), Latin subset. Google Fonts' own Latin-subset variable file, downloaded as-is. |
| `jetbrains-mono-nerd-{regular,medium}.woff2` | ~988 KB each | Full font, all ~9,000 glyphs. Kept on the CDN as a fallback; **not** referenced by the style guide. |

The production `@font-face` rules in `reference/style-guide.html` point at:
`https://cdn.rossie.net/fonts/jetbrains-mono-nerd-{regular,medium}-min.woff2`,
`outfit-latin-var.woff2`, and `urbanist-latin-var.woff2`.

## Cloudflare Pages setup (JR — dashboard work)

You already host a site (`rossie.net` / `www.rossie.net`) on Pages. Use a **separate
Pages project** for CDN assets so font files never tangle with your main site.

1. **Create the project.** Cloudflare dashboard → **Workers & Pages** → **Create** →
   **Pages** → **Upload assets** (not "Connect to Git").
2. **Name it** `cdn-rossie` (the name only affects the temporary `*.pages.dev` URL).
3. **Upload.** Drag the **contents** of `fonts/cloudflare-deploy/` into the upload box —
   i.e. select `index.html`, `_headers`, and the `fonts/` folder together. Do *not* drag
   the `cloudflare-deploy` folder itself, or files land one level too deep.
4. Click **Deploy site**. You'll get a `cdn-rossie.pages.dev` URL — test it works.
5. **Custom domain.** Open the project → **Custom domains** → **Set up a custom domain**
   → enter `cdn.rossie.net`. Since `rossie.net` is already on Cloudflare, it auto-creates
   the CNAME record. Wait for the status to go **Active** (usually < 1 min).

## Verify it worked

After `cdn.rossie.net` is Active, in a terminal:

```
curl -sI https://cdn.rossie.net/fonts/jetbrains-mono-nerd-regular-min.woff2
curl -sI https://cdn.rossie.net/fonts/outfit-latin-var.woff2
```

Expect `HTTP/2 200`, `content-type: font/woff2`, and
`access-control-allow-origin: *` (the `_headers` file sets the CORS header — required
because `style-guide.html` loads the fonts from a different origin).

Then open `reference/style-guide.html` in a browser — Nerd glyphs should render (not
boxes), and headings/body text should be Outfit/Urbanist, not a system sans fallback.

## Rebuilding the fonts

`fonts/build-fonts.sh` regenerates every file in `cloudflare-deploy/fonts/` except the
two full-font woff2. One-time toolchain setup:

```
cd fonts
/usr/bin/python3 -m venv .venv && .venv/bin/pip install fonttools brotli
```

Then `bash fonts/build-fonts.sh`. It will:

- **Subset the JetBrainsMono `.ttf`** to the `-min.woff2` files. The glyph list is
  scraped live from `GLYPHS.md` (every `U+XXXX`), so editing the catalog and re-running
  the script keeps the subset in sync. After a Nerd Fonts release, replace the two
  `.ttf` files first, then rebuild.
- **Download Outfit & Urbanist** Latin-subset variable woff2 from Google Fonts.
- **Regenerate `UNICODE-RANGE.css`** — the `unicode-range` for the `-min` `@font-face`.

After rebuilding: if `GLYPHS.md` changed, paste the new `UNICODE-RANGE.css` contents
into **both** `-min` `@font-face` rules in `reference/style-guide.html`. Then re-upload
`cloudflare-deploy/` to Pages, bump the version in `GLYPHS.md`, and re-run the
verification page.

For the full how-to — including adding a new font family — see the `font-subset` skill
(`.claude/skills/font-subset/`).

## Subset + full-font fallback

The mono `@font-face` declares the full font *and* the `-min` subset under one family
name. The subset (declared last, with a `unicode-range`) wins for catalog glyphs, so
catalog-only pages download only ~23 KB/weight. The full font is fetched lazily — only
on a page that uses a glyph outside the catalog — so off-catalog glyphs degrade to a
(heavier) correct render instead of tofu boxes. It is all-or-nothing per page: one
off-catalog character pulls the full ~987 KB for that page.

## Why Pages, not R2

Pages was chosen over R2 because it can also serve `style-guide.html` itself later if
wanted, has a simpler custom-domain flow, and supports the `_headers` file for CORS +
caching without extra config.
