# components/

This directory holds the production monogram SVGs and document templates.

## Pending production
- `monogram-light.svg` — Primary mark for light surfaces
- `monogram-dark.svg` — Primary mark for dark surfaces
- `monogram-mono.svg` — Monochrome variant for fax, emboss, single-color print

See `prompts/for-design-tools.md` for prompts to use with Adobe Firefly or Illustrator AI to refine your existing JR monogram into these production variants.

## Templates

The `templates/` subdirectory will hold reusable document scaffolds — stationery, business cards, R—Net dashboard skeletons, document covers — as they're built.

Per `SYSTEM.md §15`, components are deferred to point of need. Build them as you have specific use cases, not in advance.
